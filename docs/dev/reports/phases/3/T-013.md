# T-013 - Chromium activation and native boundary

Chromium MV3 uses an action, side_panel and service worker with only activeTab, scripting and sidePanel permissions. No content_scripts, permanent hosts, storage, app tab or backend. The synchronous toolbar callback opens the window's panel before starting injection into only the captured tab frame zero in ISOLATED world. Unsupported/private tabs skip injection; denied injection still notifies that captured window/tab so sidebar probing yields disabled availability. Opening the sidebar document only probes; startup does not activate a page. All three runtime entries are bundled local IIFEs and sidebar assets/manifest/license/build metadata are staged explicitly.
