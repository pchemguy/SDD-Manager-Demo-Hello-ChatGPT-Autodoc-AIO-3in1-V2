# T-008 - Windows runtime package

The packager assembles Electron 45.0.0 win32 x64 with the local common renderer and host, then archives every runtime resource at the ZIP root. It downloads through @electron/get with default SHA-256 validation; cache reuse also validates the upstream checksum. No Linux Electron binary, Wine, Node installation or development server is a deployed dependency. The portable package is unsigned, not a signed installer or store distribution.

RED: the archive completeness test failed because the Windows archive was absent. First generated-package inspection exposed an obsolete test assumption about ANGLE DLL names: the exact Electron 45 upstream SDK instead includes dxcompiler and SwiftShader libraries. Inspection of the original SDK established the correct inventory. GREEN: electron suite 5 passed. Tests verify MZ/PE signature, AMD64 machine type, local entry/version, CRC, bundled renderer byte identity and byte-for-byte preservation of every upstream runtime resource except the deliberately replaced executable/default app. All upstream licenses/locales are retained. Packager rewrites executable metadata; its actual PE architecture was checked.

The package command supports browser, electron and cumulative all selections and clears only its versioned output directory before assembly. Archives exclude source, credentials and development tooling through explicit staging and the safe archive utility.

Native Windows launch, OS security behavior, extraction through Windows Explorer and SmartScreen/signature presentation were unavailable on this Linux host and are excluded. Static package/PE and modeled host tests do not establish native execution. TODO: None.
