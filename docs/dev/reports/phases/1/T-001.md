## Download diagnosis and recovery

The normal Chromium shell URL returned HTTP 200, text/html, 195 bytes and a Site Unavailable HTML body; ZIP central-directory validation failed. The Firefox CDN URL returned the same HTML. The official Microsoft Firefox fallback returned a ZIP signature and the runner extracted Firefox 157.0 revision 1555 successfully. The installer's following FFmpeg download failed and its own stale-threshold lock check exited; the owned installer terminated. No unrelated lock was removed.

Chromium/FFmpeg were recovered by selective extraction from the matching official mcr.microsoft.com/playwright:v1.64.1-noble image. The AMD64 manifest digest is sha256:d65108d1a8095d8b0c4a5e32bf1807a40a5ce90ff0c78473e1116b1c243235e8. Manifest and config digest checks passed. Image history identifies layer 4 as Chromium/FFmpeg, with separate later Firefox/WebKit layers that do not modify those browser trees. Layer sha256:eb005fbb9cada4cd1b9476577a1eef0e000a2a0e9e319f84ecf4bfff1a4f28bb was verified at 314299121 bytes before extraction. Extracted 613 safe entries only into chromium-1248, chromium_headless_shell-1248 and ffmpeg-1013 under the absolute project .tools/browsers directory. Extraction rejected traversal/escaping links/devices and handled relevant whiteouts; executable modes were retained. No container isolation is claimed from extraction.

Actual Chromium launch logs identify chromium_headless_shell-1248/chrome-headless-shell-linux64/chrome-headless-shell, version 156.0.8078.4. Its default Playwright arguments already include --no-sandbox. Nonfatal DBus socket warnings did not prevent context creation, interaction, rendering or cleanup. Full Chromium has been provisioned but its native-extension mode is not yet assessed; that belongs to the extension phase.

Firefox initially launched but page creation crashed. DEBUG=pw:browser logs identified content-process writes to /proc/self/uid_map failing with EPERM and child crashes. The ignored .tools/capabilities.json enables this override for tools/check.py via firefoxContentSandboxOverride: true; it is not applied globally or to arbitrary external webpages. ## Reproduction and limits

Use npm ci and python -m pip install --target .tools/python -r requirements-dev.txt. Set PLAYWRIGHT_BROWSERS_PATH to the absolute repository .tools/browsers path for both the runner install command and checks. The pinned CLI dry run supplies revision/download URLs. The official Microsoft fallback base for Firefox is https://playwright.download.prss.microsoft.com/dbazure/download/playwright; browser- and image-specific recovery follows the repository Playwright guidance and the verified digests above. Failed CDN payloads are not valid browser assets.
