Older Firefox versions and their metadata handling were not exercised.

Native toolbar/side-panel integration is unavailable in this environment. The headless shell remains usable for local DOM/model checks. Interactive browser-chrome/sidebar testing is not provided by the available Firefox harness; native Firefox toolbar/permission/interaction/lifecycle scenarios remain unverified.

## Excluded and remaining unverified behavior

Native Windows launch, Windows Explorer extraction, SmartScreen/signature presentation and actual Electron renderer enforcement are unavailable on the Linux build host and excluded. Cross-built PE/archive and modeled host checks do not establish native Windows execution. Native Chromium/Firefox toolbar/sidebar grants, isolation and full lifecycle matrix remain untested as detailed above; modeled transport is not a native compatibility pass. API-floor browser versions, native browser-toolbar zoom and OS-window focus were not exercised. CSS zoom/effective viewport and headless keyboard inputs were exercised. No signing, store submission, mobile platform or persistent preference behavior is delivered.
